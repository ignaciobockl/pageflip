# @pageflip/renderers

Meta package for PageFlip renderers.

## Install

```bash
npm install @pageflip/renderers
```

## Renderers

- [`@pageflip/renderers-image`](./image) - Image renderer
- [`@pageflip/renderers-pdf`](./pdf) - PDF renderer
- [`@pageflip/renderers-rtf`](./rtf) - RTF renderer
- [`@pageflip/renderers-video`](./video) - Video renderer
