# PageFlip Specification

This repository contains the base monorepo foundation for PageFlip.

## Scope

- Bun-native monorepo
- Shared tooling for linting, typing, testing, and releases
- Core, framework, theme, renderer, and web component package boundaries
- Apps for documentation, playground, and benchmarks

## Initial package map

- `@pageflip/core`
- `@pageflip/react`
- `@pageflip/theme`
- `@pageflip/renderers`
- `@pageflip/renderers-pdf`
- `@pageflip/renderers-video`
- `@pageflip/renderers-image`
- `@pageflip/renderers-rtf`
- `@pageflip/web-component`

## Non-goals for this phase

- Production implementation
- Runtime feature logic
- Publishing setup execution
