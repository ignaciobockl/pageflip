# Security Policy

## Reporting a Vulnerability

**Do not open a public issue** if you find a security vulnerability. Instead, please report it privately using GitHub's Security Advisory feature:

1. Go to the [Security] tab in this repository
2. Click "Report a vulnerability"
3. Fill in the details of the vulnerability
4. Submit the report

This allows us to address the issue responsibly before it is disclosed publicly.

Alternatively, you can report vulnerabilities directly by emailing ignaciobockl96@gmail.com with the subject line "Security Vulnerability Report".

## Supported Versions

We support security updates for the latest published versions of each `@pageflip/*` package.

| Version | Supported |
|---------|-----------|
| 0.1.x   | ✅        |
| < 0.1.0 | ❌        |

## Security Considerations

- Keep your version of `@pageflip/*` packages up to date
- Review the changelog for security-related updates
- Report any suspicious activity or potential security issues

## Disclosure Timeline

When a vulnerability is reported:

1. We acknowledge receipt within 48 hours
2. We assess and reproduce the issue
3. We develop and test a fix
4. We release a security patch
5. We publish details about the vulnerability

We ask that reporters allow reasonable time for us to address the vulnerability before public disclosure.

Thank you for helping keep PageFlip secure.
