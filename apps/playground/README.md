# PageFlip Playground

Interactive demo showcasing all PageFlip features.

## Quick Start

```bash
# From repo root
bun install
bun run dev:playground
# Opens http://localhost:5173
```

## Features Demonstrated

- **Main Demo**: 6-page flip book with cover, content, back cover
- **Theme Toggle**: Light/Dark mode with localStorage persistence
- **Layout Toggle**: Fixed (800x600) vs Stretch (responsive)
- **External Controls**: Hooks-based navigation (usePageFlip, usePageFlipControls, usePageFlipState)
- **Component Library**: Toolbar, PageIndicator, ZoomControls, FullscreenToggle
- **Keyboard Shortcuts**: Arrow keys, Home/End, Space, +/- for zoom, f for fullscreen
- **Responsive**: Works on mobile, tablet, desktop
- **Dark Mode**: Full support with CSS variables

## Available Scripts

```bash
# Development
bun run dev              # Start Vite dev server
bun run dev:playground   # Start playground only

# Build
bun run build            # Production build

# Testing
bun run test             # Unit tests (Vitest)
bun run test:coverage    # Coverage report
bun run test:e2e         # E2E tests (Playwright)
bun run test:e2e:ui      # Playwright UI mode
bun run test:e2e:headed  # Headed mode for debugging

# Storybook
bun run storybook        # Start Storybook on port 6006
bun run build-storybook  # Build static Storybook

# Quality
bun run lint             # Lint + format
bun run typecheck        # TypeScript check
```

## Playwright E2E Tests

```bash
# Run all tests
bun run test:e2e

# Headed mode (see browser)
bun run test:e2e:headed

# UI mode (interactive)
bun run test:e2e:ui

# Specific test file
bun run test:e2e -- tests/e2e/playground.spec.ts
```

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `→` / `Space` | Next page |
| `←` / `Shift+Space` | Previous page |
| `Home` | First page |
| `End` | Last page |
| `+` / `=` | Zoom in (future) |
| `-` / `_` | Zoom out (future) |
| `0` | Reset zoom (future) |
| `f` | Fullscreen (future) |
