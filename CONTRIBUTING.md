# Contributing

## Required flow

1. Open or reference an issue.
2. Wait for owner approval on the issue.
3. Sign the CLA.
4. Open a pull request linked to the approved issue.
5. Wait for owner approval before merge.

## Rules

- No direct feature work without an approved issue.
- Keep changes focused and minimal.
- Follow repository lint, typecheck, test, and release rules.
- Add a changeset for user-facing changes.
- Respect trademark and governance documents.

## Pull requests

- Reference the issue in the PR body.
- Describe scope, risk, and validation.
- Ensure CI passes before requesting review.
